about downrabbit

a tiny media downloader that lives in your browser.

paste a link, get the file. direct links stream straight to your disk — multi-connection, resumable, no account. platform pages run through the optional local bridge.

honest scope: the webapp itself is still serverless. YouTube/TikTok/etc. need the small bridge on your machine; Spotify is DRM and stays unsupported.

what can i download?

✓ direct file links

a URL that points straight at a file — usually ends in an extension, and the host allows cross-origin reads.

https://cdn.example.com/clip.mp4
https://files.example.org/song.mp3
✓ platform pages · with the local bridge

start the tiny local bridge once and downrabbit can fetch YouTube, TikTok, Instagram, Reddit, X, Facebook, Vimeo, Twitch, SoundCloud, Bilibili, Dailymotion, Pinterest, Tumblr and most other sites yt-dlp supports. the download runs on your machine — no server of ours.

cd bridge
.\setup.ps1
.\start.ps1

some sites (Instagram, Facebook, X, age-restricted YouTube) need your browser cookies. start the bridge with BRIDGE_COOKIES_FROM_BROWSER=chrome (or edge/firefox).

first time? your browser may ask to allow local network access — click Allow so the bridge can connect.

1080p+ and MP3 conversion use ffmpeg; setup.ps1 installs a build with MP3 support.

✕ spotify

Spotify streams are DRM-protected, so no downloader can save them. use SoundCloud or a video mirror instead.

tip

if a host blocks in-app reads, downrabbit offers a browser download fallback. turn on background downloads in settings to let your browser finish files even after you close this tab.
