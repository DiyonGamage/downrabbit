01 / capabilities

Everything, minus the middleman.

No browser tab, no queue, no upload. The engine runs on your machine and fetches directly from the source.

01

any site yt-dlp knows

YouTube, TikTok, Instagram, X, Reddit, SoundCloud, Vimeo, Twitch and thousands more.

02

best quality, or yours

Highest available by default. Add 720p when you want a smaller file.

03

audio and mp3

Add audio for the original stream, or mp3 to convert with ffmpeg.

04

parallel by default

Eight range requests at once. Fast on sites that throttle single streams.

05

saves where you want

Downloads by default. -o and --name when you care.

06

yours, privately

Runs locally. No account, no analytics, no uploads, no server of ours in the middle.

02 / reference

One word. Plus a link.

Everything after the link is optional. Use a shorthand, or the long-form flags if you prefer.

downr <link>

best quality video into your Downloads folder. run it with no arguments and it asks for a link.

downr <link> 1080p

cap the resolution: 2160p / 1440p / 1080p / 720p / 480p / 360p.

downr <link> audio

audio only, original format (m4a, opus…).

downr <link> mp3

audio only, converted to mp3.

downr <link> -q 1080 / -a / -m

the long forms, if you prefer flags.

downr <link> -o "D:\Videos"

save somewhere else. relative paths, ~ and folders with spaces all work.

downr <link> --name "my clip"

choose the file name (the extension is kept correct).

downr <link1> <link2> …

more than one link is fine. they download one after another.

downr --help

this page, in your terminal.

03 / one command

Install it. Keep it local.

Installs the engine, yt-dlp and ffmpeg next to your user account. No admin, no dependencies to manage.

$powershell -NoProfile -ExecutionPolicy Bypass -c "irm https://downrabbit.pages.dev/install.ps1 | iex"
paste into cmd or PowerShell. installs to %LOCALAPPDATA%\downrabbit and puts downr on your PATH. open a new terminal afterwards. to remove: delete that folder and drop it from PATH.
$curl -fsSL https://downrabbit.pages.dev/install.sh | sh
paste into Terminal. needs node 18+ (brew install node). installs to ~/.local/share/downrabbit, command in ~/.local/bin.
$curl -fsSL https://downrabbit.pages.dev/install.sh | sh
paste into your shell. needs node 18+. installs to ~/.local/share/downrabbit, command in ~/.local/bin (it tells you if that folder isn't on PATH).
$curl -fsSL https://downrabbit.pages.dev/install.sh | sh
paste into Termux (free on Play Store / F-Droid). it installs node, yt-dlp and ffmpeg with pkg and asks once for storage permission so files land in your Downloads folder. phones on iOS can't run local programs — download on a computer instead.

04 / questions

Small footprint. Fewer surprises.

Everything runs on your machine. Here is what that means in practice.

is it really free?

Yes. Apache-2.0 source, no account, no ads, no paid tier, no analytics. The only cost is your own bandwidth and about 120 MB of disk.

is it safe?

The installer is a plain text script you can read before running (github.com/DiyonGamage/downrabbit). It downloads signed Node.js, yt-dlp and an ffmpeg build from their official releases into your user folder. Nothing runs as admin, nothing listens on a public port, and downloads only happen when you ask for them.

where do my files go?

Your Downloads folder — %USERPROFILE%\Downloads on Windows, ~/Downloads on macOS/Linux, ~/storage/downloads on Android. Use -o to pick a different folder.

YouTube wants me to sign in for some videos

Private, age-restricted or members-only videos need your browser session. Start a download with your cookies available: set BRIDGE_COOKIES_FROM_BROWSER=chrome (or edge / firefox) in the terminal before running downr. Public videos never need this.

does it keep working when sites change?

The engine refreshes yt-dlp automatically in the background. If a site still breaks, re-run the install command — it updates everything in place and keeps your files and settings.

can i use it on my phone?

Android, yes — through Termux with the same one-line install. Files land in your Downloads folder and play in any app. iPhones and iPads can't run local programs, so use a computer for platform links.

why is it faster than downloader websites?

Those sites queue you behind everyone else and stream through their server. Downrabbit runs on your machine, fetches from 8 parallel connections and never uploads your file anywhere — the ceiling is your own internet, not someone else's queue.

how do i uninstall it?

Windows: delete %LOCALAPPDATA%\downrabbit and remove that bin folder from your PATH. macOS/Linux: rm -rf ~/.local/share/downrabbit ~/.local/bin/downr. That's the whole footprint.
